MOEENCLIPS WEBSITE DEMO

HOW TO RUN
1. Extract the ZIP file.
2. Open the moeenclips_website folder.
3. Double-click index.html, or open the folder in VS Code and use Live Server.

FEATURES
- Responsive desktop and mobile layout
- Search and category filters
- Video cards with preview player modal
- Save videos (stored in browser localStorage)
- Watch history (stored in browser localStorage)
- Theme toggle
- Upload local video files to the current browser session demo feed
- Share link (uses native share where available or clipboard)

IMPORTANT
This is a front-end demo, not a production full-stack service yet. Uploads are local to the current browser session and are NOT publicly uploaded or shared between users. A real production platform needs a backend, user authentication, cloud video storage, database, moderation and deployment configuration. Demo thumbnails require an internet connection.
